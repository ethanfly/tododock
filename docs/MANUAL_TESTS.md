# TodoDock 手工验收清单

## 通用准备

- 使用发布构建，不使用浏览器预览。
- 准备至少一个未来 2 分钟到期、一个已经逾期和一个无 deadline 的 Todo。
- 记录系统版本、时区、应用版本、显示器缩放和窗口管理环境。
- 测试前备份现有数据；不要使用真实敏感 Todo 内容。

## 快速记录与 Markdown

- 在另一个应用获得焦点时按待办窗口快捷键，隐藏的列表应在 250ms 目标内出现；窗口已显示时再按应变为隐藏。
- 按新建待办快捷键打开新建窗口；窗口已显示时再按应变为隐藏，隐藏后再按重新打开。
- 关闭全局快捷键后重复上述动作，确认窗口不出现；重新启用或修改组合键后无需重启即可生效。
- 使用中文 IME 组合输入并按回车选词；组合态不能误创建 Todo。
- 输入标题后回车保存，重启应用确认 SQLite 持久化。
- 展开快速记录和任务编辑页，确认聚焦环完整显示在容器内，不被圆角或滚动区域裁切，且布局不发生跳动。
- 在所见即所得模式编辑标题、强调、列表、任务列表、代码和链接；切换到源码模式确认 Markdown 语法完整，再切回视觉模式确认内容不丢失。
- 粘贴带样式的网页内容，确认只插入纯文本；输入远程图片语法，确认显示占位且不自动联网加载。
- 粘贴原始 HTML 和 `javascript:` 链接，确认不执行且不能打开危险协议。
- 开启系统“减少动态效果/Reduce motion”后重新打开应用，确认弹层、卡片、焦点与加载状态不再播放显著动画，仍可正常操作。

## 窗口与多显示器

- 从自定义标题栏自由拖动窗口；按钮区域不能误触发拖动。
- 移动并调整窗口尺寸，正常退出后重启，确认位置和尺寸恢复；删除保存时所在显示器后再次启动，窗口必须回到可见显示器。
- 窗口已贴边隐藏时关闭“贴边隐藏”并保存，确认窗口立即完整显示，不需要再次从托盘或快捷键唤回。
- 分别拖到左、右、上边缘，确认吸附到当前显示器工作区。
- 点击其他应用，确认延迟后只留下 8px 把手；移入把手、托盘点击和全局快捷键均可唤回。
- 连续执行三次“失焦隐藏→把手/快捷键唤回”，确认程序化移动不会清空贴边状态或把窗口永久留在屏外。
- 窗口处于贴边/曾隐藏状态时从托盘退出并重启，确认恢复的是完整可见窗口，不保存只有 8px 可见的屏外坐标。
- 点击列表中的编辑或待办标题，确认弹出独立的编辑窗口而不是主窗口模态框；Esc/关闭只关掉该窗口。新建待办、设置、编辑窗口打开时切换焦点，确认主窗口不会自动隐藏。
- 切换置顶，确认层级变化且重启后保持。
- 在不同 DPI 的显示器之间拖动，确认无跳变；断开外接显示器，确认窗口仍可见。
- 测试任务栏/Dock 普通和自动隐藏状态；TodoDock 不得覆盖为不可唤回状态。

## Deadline 与提醒

- 首次设置 deadline 时处理通知权限允许和拒绝两条路径；同一运行周期内再次保存不应重复弹授权；设置页显式请求可重试。拒绝或系统通知投递失败时，应用内横幅仍应展示并可跳转到对应 Todo。
- 分别创建“提前提醒”和“到期时”Todo，确认每项只通知一次；提前提醒触发后到 deadline 不得再次通知，重启也不能重复投递。
- 为一个 Todo 选择“不提醒”，确认提前和到期都不出现；选择“到期时”后只出现到期通知。
- 在通知尚未授权时保存“不提醒”的 Todo，确认不会弹权限请求；输入无效或夏令时不存在的 deadline，确认先显示时间错误且不会请求通知权限。
- 提醒前完成或删除 Todo，确认不再通知。
- 让系统休眠跨过提醒时间，恢复后确认 24 小时内漏掉的提醒会补发。
- 开启跨午夜静默时段，确认期间不通知；结束后积累多项时只出现一条汇总通知。
- 将系统时区切到存在夏令时的区域，验证静默结束落在跳时缺口或回拨歧义区间时不会提前发出提醒。
- 在窗口隐藏时触发提醒并强制结束进程；重启后应用内横幅仍应出现。查看或忽略该横幅后再次重启，确认不再重复出现。
- 切换时区和夏令时边界，确认 UTC 存储对应的本地展示正确。

## 生命周期与数据

- 启用“关闭到托盘”后关闭窗口，确认进程和提醒继续；托盘“退出”才结束进程。
- 首次关闭到托盘说明弹出后模拟窗口隐藏失败，确认“已解释”不会被错误保存，下一次关闭仍会显示说明。
- 分别点击托盘“快速新建”“今天”“设置”，确认窗口显示并进入正确视图。
- 禁用“关闭到托盘”后关闭窗口，确认进程退出。
- 开机启动默认关闭；启用后登录启动应保持后台，不抢焦点。
- 创建 JSON、Markdown 导出和备份，确认文件位于应用数据目录，JSON 不含投递日志，Markdown 保留正文语法。
- 删除一项合成测试 Todo，确认撤销入口出现并能恢复原状态；等待撤销入口消失后确认列表仍隐藏该项。
- 导入前确认预览数量；导入失败不改变数据；导入成功前应自动产生备份，成功后主题、快捷键、开机启动和窗口设置保持不变。
- 制造相同 ID 的新旧导出，确认更新时间较新的记录胜出。
- 使用合成数据执行“恢复”，确认预览列出新增/替换/移除数量、执行前生成当前数据备份，完成后 Todo 与设置和所选备份完全一致；取消确认时不得改变数据。
- 检查日志，确认不出现 Todo 标题、Markdown 正文或导入内容。

## 安装器语言

- 在简体中文 Windows 上运行 NSIS `*-setup.exe`，确认欢迎/目录/完成页为中文，且启动时不弹出语言选择框。
- 在英文 Windows 上重复，确认安装界面为英文。
- 若系统语言不在安装器语言列表中，确认回退为英文。
- MSI 使用对应语言文件名的包（如 `*_zh-CN.msi`、`*_en-US.msi`）验证界面语言。

## 平台专项

Windows 验证混合 DPI、通知中心、专注助手和任务栏自动隐藏。

macOS 验证通知权限、菜单栏、Notch 安全区、全屏 Space、签名与公证。

Linux X11 验证常见 GNOME/KDE 托盘和通知实现。Linux Wayland 验证设置页明确展示贴边能力降级，Todo、快捷键、托盘和显式隐藏仍可用。
