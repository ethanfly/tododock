# TodoDock 性能记录

## 2026-08-31 基线

环境：Windows 11 64 位（10.0.26200），AMD Ryzen 9 3900X，31.9GB 内存。数据库为内存 SQLite，Rust `dev` 测试构建。

数据集：10,000 条开放 Todo，其中 104 条匹配搜索词。连续执行 30 次标题/正文搜索并排序。

结果：本轮搜索 P95 为 7.82ms，提醒扫描 P95 为 15.16ms；均通过调试探针 1000ms 的宽松门禁，也低于产品规格的 100ms 查询目标。六目标 CI 会显式运行同一组探针并保留各平台日志。

发布构建前端就绪：首次样本 751ms；代码拆分后的 5 次暖启动范围为 645–666ms，中位数 659ms。它满足 P95 800ms 上限，但尚未达到 500ms 理想目标。全局快捷键到输入框焦点已从文件资源管理器取得一次 112ms 样本，仍需重复采样后报告 P95。

发布构建后台空闲采样：连续 20 秒时工作集 44,113,920 bytes（约 42.1MiB）、私有内存 13,766,656 bytes（约 13.1MiB）、按 24 个逻辑处理器归一化 CPU 为 0.0618%，进程保持响应。该结果满足 120MB 与 0.2% 工程目标，但 macOS/Linux 仍需独立采样。

前端生产拆包：主入口 345.78 kB（gzip 105.00 kB），Markdown 渲染块 154.77 kB（gzip 46.37 kB），所见即所得编辑器块 10.26 kB（gzip 3.78 kB），CSS 28.62 kB（gzip 6.07 kB）。编辑器在视觉或源码编辑期间卸载隐藏解析模板，避免长正文按字符重复解析；列表查询使用请求版本门控，旧搜索响应不会覆盖新查询；编辑器和 Markdown 解析器均不进入冷启动主包；系统启用“减少动态效果”时会关闭主要过渡和滚动动画。

Windows 发布包体积：五语言 MSI 中，en-US/ja-JP/ko-KR 各为 6,037,504 bytes（5.76 MiB），zh-CN/zh-TW 各为 6,033,408 bytes（5.75 MiB）；NSIS 安装器为 4,482,347 bytes（4.27 MiB），使用 Rust 1.85.0 构建。全部均为未签名本地验收产物；签名后的体积需在发布流水线重新记录。

数据库探针、Windows 就绪时间、常驻内存和空闲 CPU 已有基线；完整 UI 搜索、全局快捷键 P95 以及 macOS/Linux 同项数据仍待发布前补齐。
