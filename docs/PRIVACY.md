# TodoDock 隐私审计

审计日期：2026-08-31。范围为当前源码、Tauri capability、内容安全策略、日志调用和诊断导出结构。

## 数据与网络边界

- Todo、Markdown、设置、提醒投递记录和窗口状态只写入操作系统应用数据目录。
- 默认没有 `fetch`、`XMLHttpRequest`、`WebSocket` 或自动联网；未配置遥测、账号或自动更新器。
- 禅道同步是可选能力：仅当用户在设置中填写禅道地址/账号并主动点击「同步禅道」时，Rust 才会向该地址发起 HTTPS/HTTP 请求。请求只用于登录和读取任务，密码只保存在本机设置中，日志和诊断文件不得包含禅道密码或任务标题。
- CSP 的 `connect-src` 只允许应用自身与 Tauri IPC；`img-src` 只允许自身资源、Tauri asset 和 `data:`。
- capability 只允许主窗口调用所需窗口/通知接口，并允许把 `http`、`https`、`mailto` 链接交给系统 opener。该能力只在用户点击已通过协议校验的 Markdown 链接后调用。
- Markdown 远程图片渲染为保留原语法的本地占位，不创建远程图片请求；视觉编辑器粘贴和拖放只接收纯文本。

## 日志与诊断

- Rust 日志记录错误类别、系统错误和两项毫秒级性能指标，不主动记录 Todo 标题、正文或导入文件内容。
- 日志级别为 info，单文件上限 512,000 bytes，最多保留 3 份。
- 用户主动导出的诊断 JSON 只包含格式/应用版本、操作系统与架构、Wayland 状态、数据库聚合计数、快捷键健康状态和前端就绪/快捷键聚焦耗时；自动化测试断言其不含标题或正文。

## 剩余发布检查

- 每个平台的最终签名构建仍需抓取一次空闲网络流量并检查日志样本。
- 引入同步、更新、崩溃报告或第三方内容前，必须重新审查 capability、CSP、依赖和用户授权流程。
